# Machine Learning Practice

A personal repository for learning and experimenting with machine learning using Python.

I'm working through Andrew Ng's **Machine Learning Specialization by DeepLearning.AI** and using this repository to reinforce concepts through hands-on coding, visualizations, and small experiments.

## Goals

- Build a practical understanding of fundamental ML concepts and algorithms.
- Get comfortable working with Python, NumPy, Pandas, Matplotlib, and Scikit-learn.
- Understand how models are trained, evaluated, and optimized.
- Experiment with datasets, model parameters, and hyperparameters.
- Progress from basic supervised learning to more advanced ML techniques.

The focus is on **understanding how ML works through experimentation**, rather than implementing every algorithm from scratch.

## Approach

For each topic, I aim to:

1. **Learn** — Understand the underlying concepts through coursework.
2. **Implement** — Apply concepts using Python and established ML libraries.
3. **Visualize** — Plot data, predictions, costs, and training behavior.
4. **Experiment** — Change parameters, learning rates, datasets, and other variables.
5. **Document** — Record observations and lessons learned.

## Initial Experiments: Linear Regression

My first notebook explores:

- Representing training data using NumPy arrays.
- Training a linear regression model using stochastic gradient descent (SGD).
- Understanding the relationship between weights, bias, and predictions.
- Visualizing the fitted regression line.
- Measuring prediction error using mean squared error (MSE).
- Observing how learning rates and training epochs affect convergence.
- Comparing `SGDRegressor` with Scikit-learn's `LinearRegression`.

**Key takeaway:** A model defines how predictions are made, a cost function measures prediction error, and an optimization algorithm such as gradient descent adjusts model parameters to reduce that error.
